📋 Embed Your Guestbook

Choose how you want to add the guestbook to your website

🖼️ Simple iframe Embed

The easiest way to add your guestbook. Just copy and paste this code into your website's HTML. The guestbook will appear exactly as styled, but customization options are limited.

Best for: Quick setup, no coding experience needed, consistent appearance

HTML 
<iframe 
  title="Guestbook for {{.Data.Guestbook.WebsiteURL}}"
  src="{{.Data.PublicHostUrl}}/guestbook/{{.Data.Guestbook.ID}}" 
  width="100%" 
  height="600" 
  frameborder="0"
  style="border: 1px solid #e0e0e0; border-radius: 8px;">
</iframe>

Customization Options

  • Adjust width and height to fit your layout
  • Add CSS to the style attribute for borders or shadows
  • Set width="100%" for responsive sizing

⚡ Custom JavaScript Embed

Full control over the appearance. The copied HTML defines your form; JavaScript handles submissions and loads messages. You style it to match your website.

Best for: Complete design control, matching your site's theme, advanced customization

HTML + JavaScript 
<!-- Guestbook Script -->
<script defer src="{{.Data.PublicHostUrl}}/resources/js/embed_script/{{.Data.Guestbook.ID}}/script.js"></script>
<!-- Guestbook Form -->
<div id="guestbooks___guestbook-form-container">
  <form id="guestbooks___guestbook-form" 
        action="{{.Data.PublicHostUrl}}/guestbook/{{.Data.Guestbook.ID}}/submit" 
        method="post">
    <div class="guestbooks___input-container">
      <label for="name">Name</label>
      <input type="text" 
             id="name" 
             name="name" 
             placeholder="Your Name" 
             required>
    </div>
    <div class="guestbooks___input-container">
      <label for="website">Website (optional)</label>
      <input type="url" 
             id="website" 
             name="website" 
             placeholder="Website (optional)">
    </div>
    {{.Data.EmailFieldHTML}}
    <div id="guestbooks___challenge-answer-container"></div>
    <div class="guestbooks___input-container">
      <label for="text">Message</label>
      <textarea id="text" 
                name="text" 
                placeholder="Leave your message here..." 
                rows="4"
                style="width: 100%; box-sizing: border-box; resize: vertical;"
                required></textarea>
    </div>
    <div id="guestbooks___pow-status"></div>
    <button type="submit">Sign Guestbook</button>
    <div id="guestbooks___error-message"></div>
  </form>
</div>
<!-- Attribution (optional but appreciated!) -->
<div id="guestbooks___guestbook-made-with" style="text-align: right; margin-top: 10px;">
  <small>Powered by <a href="{{.Data.PublicHostUrl}}" target="_blank">Guestbooks</a></small>
</div>
<!-- Messages Section -->
<hr style="margin: 2em 0;"/>
<h3 id="guestbooks___guestbook-messages-header">Messages</h3>
<div id="guestbooks___guestbook-messages-container"></div>

⚠️ Important: Don't change the name attributes or element ids - they're required for the form to work properly! Proof of Work requires your page to use HTTPS (secure localhost development is supported). Messages are limited to 2,500 Unicode characters, names to 200 characters, and website URLs to 2,048 bytes.

Private email collection is off by default. When enabled in guestbook settings, this snippet includes your optional email field. Copy that field into any existing custom embed: it is never inserted automatically. Keep it optional and use a UTF-8 page for labels in your language. If you disable collection, remove the field from your copied HTML. Existing addresses remain in your dashboard; newly submitted addresses are discarded while collection is disabled. Label and help changes also need to be copied into existing HTML.

Confirmation messages and redirects are different: changes in guestbook settings apply on the next submission, with no re-embedding required. The script adds a confirmation element only when there is text to show. Its appearance is controlled by your site's CSS using #guestbooks___success-message.

Styling Tips

  • Add your own CSS classes to style the form elements
  • Customize the button text and placeholder messages
  • Rearrange the form layout to match your design
  • Style the messages container to fit your theme

⚙️ Advanced Configuration

Additional parameters for advanced users who want to customize the guestbook's behavior.

After Submission

In guestbook settings, opt into a confirmation message in your own language (up to 2,000 characters of plain text) or an absolute HTTP(S) thank-you page URL. Feedback is disabled by default for both new and existing guestbooks. If messages need approval, explain that in your confirmation. These settings work with existing JavaScript embeds without adding a status element to your HTML.

Hidden Form Parameters

Add these hidden inputs to your form for extra functionality:

🔄 Custom Redirect URL

Redirect users to a specific page after a message is saved. This nonempty input overrides the guestbook's post-submit setting, including a configured confirmation message.

HTML 
<input type="hidden" 
       id="redirect_to_url" 
       name="redirect_to_url" 
       value="https://yoursite.com/thank-you">

💡 Note: Redirects work for both JavaScript and normal form submissions. In an iframe, navigation stays inside the iframe; your destination must allow embedding. URLs must resolve to HTTP(S), cannot contain embedded credentials, and are limited to 2,048 bytes. Legacy relative URLs in this input resolve against the Guestbooks submission URL, not your site's URL. Existing JavaScript embeds with this input will now actually navigate; previously only the background request followed the redirect. Remove the input if you do not want navigation.
